Sharing schedule

According to the project’s data management plan, the datasets will be opened to researchers after the final report is submitted to TÜBİTAK. The decision and news data were produced from publicly available sources. The X data contains account fields such as user name and follower count, so these fields will be removed or anonymised in the shared set.

What can be requested now

Codebook v4.3 (44 criteria, anchor definitions, and application rules), the source list of the news archive, and the definition of the frame are sent by e-mail in response to research requests. The request should state the purpose, the institution, and the intended use.

Corrections and contributions

If you think a decision-news link in the archive is missing or wrong, you can report it, if possible with the address and date of the news item. Reports go through the same verification protocol, and accepted ones are added to the next version of the archive.

Condition of use

Work that uses the data or the codebook must state the version and date accessed, together with the citation on the Data › How to Cite This Source page.

Requests and reports should be sent to aymed@uludag.edu.tr.
